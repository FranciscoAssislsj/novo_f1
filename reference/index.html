    Ingestão¶

    Montagem de query strings no formato de filtros da OpenF1.

    A OpenF1 usa operadores no próprio nome do parâmetro (speed>=315). Em params o httpx codificaria a chave speed>= como speed%3E%3D=315, quebrando o operador; por isso a query é montada aqui, à mão. Na transmissão o httpx ainda percent-encoda </> (%3C/%3E), forma que a API aceita normalmente.

    build_query(filters) ¶

    Monta a query string a partir de um mapeamento de filtros.

    A chave pode trazer o operador no final ("date>=", "speed>"); sem operador, usa-se igualdade. Listas geram parâmetros repetidos e None é ignorado.

    Parameters:

    Name Type Description Default
    filters Mapping[str, FilterValue]

    Mapeamento campo[operador] -> valor.

    		 required

    Returns:

    Type Description
    str

    Query string sem o ? inicial.

    Raises:

    Type Description
    ValueError

    Se uma chave não seguir o formato campo[operador].
    Example

    build_query({"session_key": 9161, "speed>=": 315}) 'session_key=9161&speed>=315'

    Cliente HTTP da OpenF1 com retry, backoff e intervalo mínimo entre chamadas.

    get(endpoint, filters=None) ¶

    Faz um GET no endpoint e devolve os registros.

    Uma resposta 404 é tratada como "sem resultados" (a OpenF1 responde assim a filtros sem correspondência).

    Parameters:

    Name Type Description Default
    endpoint str

    Nome do endpoint (ex.: "laps").

    		 required
    filters Mapping[str, FilterValue] | None

    Filtros no formato aceito por build_query.

    		 None

    Returns:

    Type Description
    list[dict[str, Any]]

    Lista de registros JSON.

    Raises:

    Type Description
    HTTPStatusError

    Em erro HTTP não recuperável ou após esgotar as tentativas.
    TransportError

    Em falha de rede após esgotar as tentativas.

    Funções finas por endpoint da OpenF1.

    partition_name(**parts) ¶

    Monta o nome do arquivo a partir de pares chave=valor.

    Example

    partition_name(session_key=9161, driver=1, lap=5) 'session_key=9161_driver=1_lap=5'

    Acesso "cache-or-fetch": lê do Parquet local ou busca na API e grava.

    Repository ¶

    Fonte única de DataFrames para o CLI e o dashboard.

    O histórico é imutável: se o arquivo do cache existe, a API não é chamada. A exceção são meetings e sessions do ano corrente, que expiram após calendar_ttl_hours. Respostas vazias não são gravadas, para que dados publicados mais tarde (ex.: resultado oficial) sejam buscados de novo.

    Name Type Description Default
    client OpenF1Client

    Cliente da OpenF1.

    		 required
    store ParquetStore

    Cache em Parquet.

    		 required
    calendar_ttl timedelta

    Validade do calendário do ano corrente.

    		 timedelta(hours=24)
    now Callable[[], datetime]

    Relógio injetável (UTC).

    		 lambda: now(UTC)

    COMPOUND_COLOURS = {'SOFT': '#DA291C', 'MEDIUM': '#FFD12E', 'HARD': '#F0F0EC', 'INTERMEDIATE': '#43B02A', 'WET': '#0067AD', 'UNKNOWN': '#8A8A8A'} module-attribute ¶

    Paradas com tempo no pit lane e tempo parado.

    Usa lane_duration (pit_duration é depreciado e só é lido como alternativa quando lane_duration não vier). stop_duration só existe a partir do GP dos EUA de 2024; antes disso fica nulo.

    tyre_timeline(stints, drivers) ¶

    Stints prontos para um gráfico de Gantt (um retângulo por stint).

    lap_end nulo (stint em andamento ou de uma volta) usa lap_start.

    Evolução de posições e gaps ao longo da sessão.

    gaps_series(intervals, drivers) ¶

    Série de gaps (s) para o líder e para o carro à frente.

    "+N LAP(S)" vira gap nulo e laps_down = N. O líder é a amostra com gap_to_leader e interval nulos (gap 0); um gap_to_leader nulo com interval preenchido é ruído da API e fica nulo.

    laps_down(value) ¶

    Número de voltas de atraso em textos como "+1 LAP" (0 se não houver).
